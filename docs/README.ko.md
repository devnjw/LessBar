# Less Bar

메뉴 막대에 필요한 아이콘만 남겨두세요. 화살표를 클릭하거나 메뉴 막대 빈 공간에 마우스를 올리거나 클릭해 숨긴 아이콘을 펼칠 수 있습니다.

[다운로드](https://github.com/devnjw/LessBar/releases) · [English](../README.md)

## 설치

1. 릴리스의 **Assets**에서 **universal `.dmg`** 파일을 받습니다. Apple Silicon과 Intel 공용이며, `Source code`는 설치 파일이 아닙니다.
2. DMG를 열고 **Less Bar**를 **Applications**로 드래그합니다.
3. 응용 프로그램에서 Less Bar를 실행하고 설정 창에서 동작을 선택합니다. Dock 아이콘은 없으며, 응용 프로그램이나 Raycast에서 다시 실행하면 설정을 열 수 있습니다.

공증 여부는 릴리스 설명에 표시합니다. **unnotarized** 파일은 개발자 미리보기로 macOS가 실행을 차단할 수 있습니다. 공증된 버전을 권장하며 Gatekeeper를 끌 필요는 없습니다. 개발자는 [소스 빌드](../README.md#build-from-source)도 가능합니다.

macOS 13–26 대상입니다. **macOS 27 이상에서는 숨김 기능이 비활성화됩니다.** 현재 실제 사용 검증 환경은 macOS 26.6.2 / Apple Silicon입니다. Intel과 이전 macOS는 추가 실기 검증이 필요합니다.

## 사용법

- 메뉴바에 포인터를 올리고 **⌘ 키를 누르면** 모든 영역과 경계가 표시됩니다. 아이콘을 경계 너머로 드래그해 숨길 위치를 정합니다. 별도 설정 없이 언제든 배치할 수 있습니다.
- 화살표가 표시되어 있으면 클릭해 아이콘을 펼치거나 숨깁니다. 오른쪽 클릭하면 설정·사용 방법·종료 메뉴가 열립니다.
- **마우스를 올리면 아이콘 표시**, **빈 공간을 클릭하면 아이콘 표시**를 독립적으로 켤 수 있습니다. **화살표 표시**도 별도로 선택합니다. 손쉬운 사용 권한이 없으면 화살표를 유지합니다. 빈 공간을 오른쪽 클릭하면 같은 메뉴가 열립니다.
- 응용 프로그램이나 Raycast에서 다시 실행하면 로그인 시 실행 등의 설정을 바꿀 수 있습니다.

설정 창이 열려 있는 동안에는 최소화해도 Dock과 ⌘Tab에 Less Bar가 표시됩니다. 설정 창을 닫으면 메뉴 막대 전용 모드로 돌아가며 앱은 계속 실행됩니다. 설정 창의 **언어**를 펼치면 라디오 버튼으로 **시스템 설정**, **English**, **한국어** 중 하나를 선택할 수 있습니다. 즉시 적용되고 재실행 후에도 유지됩니다. 기본값은 시스템 설정을 따릅니다. 업데이트는 Less Bar를 종료하고 응용 프로그램의 앱을 교체한 뒤 다시 실행합니다. 이전 앱이 `LessBar.app`이면 새 `Less Bar.app`으로 교체하고 응용 프로그램에 한 사본만 남겨두세요. 자동 업데이트는 없습니다.

## 복구와 제한

응용 프로그램에서 Less Bar를 다시 열면 아이콘이 펼쳐지고 설정 창이 열립니다. 앱을 종료해도 숨겼던 아이콘이 돌아옵니다. 화면 구성이 바뀌면 배치가 안정될 때까지 잠시 펼친 뒤 이전 표시 상태로 돌아갑니다.

손쉬운 사용 권한이 있으면 활성 화면공유 표시를 화살표 오른쪽의 항상 표시 영역으로 자동 정렬합니다. 이미 오른쪽에 있으면 그대로 둡니다. macOS가 이동을 거부하면 설정에 안내하며, 표시는 계속 보입니다. Less Bar를 다시 열면 재시도합니다.

다른 아이콘과 겹치면 펼치기 버튼을 옆으로 옮깁니다. 일시적인 재배치는 짧게 재확인하며, 안전한 위치를 찾지 못하면 자동으로 펼칩니다.

노치 주변의 공간 부족은 남아 있을 수 있습니다. 아이콘을 별도 패널로 복제하지 않습니다. 화면별 메뉴바의 표시 상태는 동기화됩니다. 전체 화면·노치 또는 다른 화면 배치·Intel·이전 macOS에서는 추가 실기 검증이 필요합니다. 다른 앱에서 직접 비활성화한 메뉴 막대 아이콘을 되살리는 기능은 없습니다.

개인용 프로토타입에서 업데이트했다면 기존 앱을 먼저 종료하세요. 공개 버전은 새 bundle ID를 사용합니다. 화살표 위치와 첫 실행 설정은 가져오지만, 로그인 실행은 새 앱에서 다시 켜야 합니다. 필요하면 시스템 설정에서 이전 Less Bar 로그인 항목을 제거하세요.

네트워크·분석 도구·계정이 없으며 화면 기록 권한은 요청하지 않습니다. 손쉬운 사용 권한으로 시스템 화면공유 표시를 식별하고 Command 드래그 이벤트로 정렬합니다. 빈 공간 호버·클릭 감지도 같은 권한으로 앱 메뉴의 위치와 크기를 읽습니다. 메뉴 막대의 식별자와 배치만 읽으며 이미지나 제목은 수집하지 않습니다. 로그인 실행은 사용자가 켤 때만 등록합니다.

## 설정

아이콘은 화살표 또는 호버로 펼칩니다. 기본 메뉴에는 **설정**, **사용 방법**, **종료**가 있으며, 단축키는 종료의 **⌘Q**만 제공합니다. Less Bar를 다시 열면 아이콘이 펼쳐지는 복구 동작도 유지합니다.

**로그인 시 실행**과 **화살표 표시** 아래에 **고급 설정**, **언어**, **사용 방법**을 같은 간격의 접힌 항목으로 배치합니다. **고급 설정** 안에는 **마우스를 올리면 아이콘 표시**, **빈 공간을 클릭하면 아이콘 표시**, **자동으로 숨기기**와 시간 슬라이더가 있습니다. 화살표 표시를 끄면 고급 설정이 자동으로 열리며, 다시 접을 수 있습니다. 언어 선택은 고급 설정 아래에 있습니다. 새로 설치하면 화살표와 자동 숨김은 켜지고 빈 공간 호버·클릭은 꺼져 있습니다. 화살표가 있으면 두 펼치기 방법을 모두 끌 수 있습니다. 화살표를 숨기면 최소 하나를 켜야 하며, 둘 다 꺼져 있었다면 클릭을 자동으로 켭니다. 마지막 펼치기 방법은 다른 방법이나 화살표를 켠 뒤 끌 수 있습니다.

호버를 사용하거나 화살표를 숨기면 자동 숨김이 켜짐으로 고정됩니다. 화살표를 표시하고 호버를 끄면 이전 자동 숨김 선택이 복원되며 재실행 후에도 유지됩니다. 업데이트 시 기존 화살표 표시 상태와 호버 선택을 보존합니다.

**고급 설정**은 제목 행이나 화살표를 클릭해 펼칩니다. 그 안의 **시간 설정**은 별도로 접지 않고 항상 펼쳐서 표시합니다. 창 위쪽은 고정된 채 아래쪽만 부드럽게 늘어납니다. 여기서 호버 지연(0–2초)과 자동 숨김 지연(0–10초)을 0.1초 단위로 조절합니다. 해당 기능을 켰을 때 조절할 수 있습니다. 자동 숨김은 마우스가 메뉴 막대를 벗어난 뒤 시작하며 메뉴 조작·드래그·설정 창 사용 중에는 기다립니다. 0초는 해당 조작이 끝나는 즉시 숨깁니다.

우클릭 메뉴의 **사용 방법**을 선택하면 설정 창이 열리면서 안내가 펼쳐집니다. 설정 맨 아래의 **사용 방법**을 펼치면 ⌘ 드래그로 아이콘을 배치하는 과정과 켜 둔 펼치기 방법을 짧은 애니메이션으로 보여줍니다. 설명 아래의 낮은 메뉴 막대 예시가 보이는 동안 자연스럽게 반복됩니다. 배치 예시는 아이콘을 왼쪽으로 옮기고 숨겼다가 다시 펼쳐 오른쪽으로 돌려놓습니다. 동작 줄이기가 켜져 있으면 정지 그림으로 보여주며, 예시는 실제 아이콘을 변경하지 않습니다.

**화살표 표시**가 꺼져 있고 손쉬운 사용 권한이 있을 때만 화살표를 숨깁니다. 권한이 사라지면 화살표가 돌아오며, Command 드래그 중에는 경계를 잠시 표시합니다. 앱 메뉴 숨기기는 계속 비활성화됩니다. 모든 시스템 메뉴바는 같은 표시 상태를 사용하며 화면별 겹침 검사와 복구 조작부를 유지합니다.

기존에 사용하던 상시 숨김 영역과 배치는 보존합니다. 화살표 또는 빈 공간 오른쪽 클릭 → **모든 영역 잠시 표시**, 또는 Less Bar를 다시 열어 항목을 복구할 수 있습니다. Command 드래그로 일반 숨김이나 항상 표시 영역으로 옮길 수 있습니다. 새로 설치하면 상시 숨김 영역은 만들지 않습니다.
