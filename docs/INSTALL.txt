Less Bar

Drag Less Bar.app to Applications, then open it from Applications.
Hold Command and drag the menu bar chevron to choose the boundary.
Click to hide/show icons on its left. Right-click for Settings or Quit.
Reopen Less Bar from Applications if you need to restore hidden icons.

Requires macOS 13–26. Hiding is disabled on macOS 27 and later.
Apple Silicon + Intel. English + Korean.
See release notes for testing coverage and notarization status.
A file named "unnotarized" is a developer preview, not a notarized release.
Do not disable Gatekeeper to install Less Bar.

To update: quit Less Bar, replace the app in Applications, then reopen it.
If the old copy is named LessBar.app, replace it with Less Bar.app; keep only one copy.
To uninstall: turn off Launch at Login, quit Less Bar, then move it to Trash.
